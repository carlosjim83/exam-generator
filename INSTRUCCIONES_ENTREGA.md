# Instrucciones de Entrega - TFM

Este documento resume los pasos necesarios para completar la entrega del Trabajo Fin de Máster.

## 1. Acceso al Repositorio

El repositorio es **privado** en GitHub. Se debe conceder acceso a:

- **Email**: `mouredev@gmail.com`
- **Usuario GitHub**: `mouredev`

### Pasos para dar acceso:

1. Ve a tu repositorio en GitHub: `https://github.com/tu-usuario/exam-generator`
2. Haz clic en **Settings** → **Manage access** (o **Collaborators**)
3. Pulsa **Invite a collaborator**
4. Introduce el email o username: `mouredev@gmail.com` o `mouredev`
5. Selecciona el rol **Read** (solo lectura) o **Write** según prefieras
6. Pulsa **Add mouredev to this repository**

## 2. URL del Código

Repositorio privado en GitHub (con acceso concedido a `mouredev@gmail.com`):

https://github.com/tu-usuario/exam-generator

## 4. Slides de Presentación

Las slides están desplegadas públicamente desde el propio frontend:

- **URL pública**: [https://formydable.es/slides/](https://formydable.es/slides/)
- **Archivo fuente**: [`frontend/public/slides/index.html`](./frontend/public/slides/index.html)
- Usa las **flechas del teclado** (← →) para navegar entre diapositivas.

> Las slides se sirven como archivo estático desde el directorio `public/` de Next.js.
