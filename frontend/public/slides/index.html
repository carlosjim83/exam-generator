El Problema

Los profesores dedican horas a crear exámenes manualmente a partir de documentos de clase, apuntes y libros.

  • Búsqueda manual de contenido relevante
  • Redacción de preguntas y respuestas
  • Revisión y corrección de exámenes
  • Poco tiempo para personalizar según el nivel del alumno

Solución: Automatizar la generación de exámenes usando IA con contexto real de los documentos del profesor.

La Solución

Una plataforma web que permite a los profesores:

  • Subir documentos (PDF, DOCX)
  • Generar exámenes automáticamente con IA
  • Revisar y editar las preguntas antes de publicar
  • Gestionar clases y alumnos
  • Corregir automáticamente exámenes de test
  • Recibir feedback sobre el rendimiento

Stack Tecnológico

Frontend Next.js 15 · React 19 · TypeScript · Tailwind CSS · shadcn/ui
Backend Fastify · TypeScript · Prisma ORM · Passport.js
AI & RAG Azure OpenAI GPT-4o · pgvector · Firebase Genkit
Base de Datos PostgreSQL 16 · Redis (BullMQ)
Infraestructura Azure Container Apps · Terraform · Docker
Testing Vitest · Playwright · TDD

Arquitectura

Clean Architecture + DDD

Backend

  • Domain: Entidades e interfaces
  • Application: Casos de uso
  • Infrastructure: Prisma, Azure, AI
  • Routes: Handlers HTTP

Frontend

  • App Router: Rutas Next.js
  • Features: Módulos independientes
  • Components: UI compartida
  • Lib: Utilidades, i18n, API

Pipeline RAG

Documento PDF/DOCX
    ↓
Azure Blob Storage
    ↓
Worker BullMQ: Extracción + Chunks
    ↓
Azure OpenAI Embeddings
    ↓
PostgreSQL + pgvector
    ↓
Búsqueda por similitud (cosine)
    ↓
GPT-4o genera preguntas contextualizadas

Las preguntas se generan únicamente a partir del contenido de los documentos subidos.
